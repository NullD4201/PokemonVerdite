출시 기준과 판단 근거 ↗

목표는 Windows 완성판입니다. 기획된 전 지역과 리메이크·레전즈·DLC 공간, 실시간 전투와 콘텐츠, 2–4인 전용 서버까지 포함합니다. 프로토타입과 첫 지방 완성은 중간 이정표입니다.

완료: 해당 목표 전체의 배포 기준 충족 · 진행 중: 일부 구현 · 예정: 구현 확인 전. 현재 배포 기준까지 검증 완료된 목표는 없습니다. 이 수치는 목표 충족률이며, 투입 작업량이나 남은 기간의 추정치가 아닙니다.

최근 개발 기록

코드와 저장된 검증 자료에서 확인한 변화입니다.
  1. 2026.10.18소스 점검

    탐험·투척 코드와 다음 연결 지점 확인

    이동·조준·궤적 예측 코드와 테스트맵을 확인했습니다. 동료 등록·목록은 선언 단계이며, 현재 소스 전체의 빌드를 재실행하지는 않았습니다.

  2. 2026.10.18포획 로그

    기본 포획의 성공·실패 기록 확인

    테스트 포켓몬에 볼이 충돌하고 확률에 따라 포획이 성공하거나 실패한 실행 로그가 남아 있습니다. 동료 등록과 전투 연계는 별도 작업입니다.

  3. 2026.10.17메뉴 검사

    720p·1080p 메뉴 실행 검사 통과

    저장된 자동 검사에서 메뉴 전환·설정 저장을 확인했고, 캡처 비교에서 배경 움직임과 고정된 버튼을 검증했습니다. 패키징한 게임의 검증 결과는 아닙니다.

  4. 2026.10.17플레이 기획

    탐험에서 실시간 전투로 이어지는 방향 정리

    기획서 v1.1에 직접 포획, 자동 출전, 포켓몬 직접 조작, 트레이너 지원 명령과 통신기 역할을 정리했습니다. 전투 구현 완료를 뜻하지 않습니다.
